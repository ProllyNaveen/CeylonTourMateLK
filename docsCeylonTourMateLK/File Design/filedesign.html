CeylonTourMate.lk

File Design Diagram

Table: users

Field NameData TypeSize (bytes)Remarks
idNumber4Unique ID for each user (Primary Key)
firstnameText50User's first name
lastnameText50User's last name
usernameText50Must be unique
emailText100Must be unique
passwordText255Encrypted password
phoneText15Contact number
profile_picText255File path to profile picture (default: default.png)
roleText (fixed options)1Options: tourist, tour_guide, shop_owner, hotel_owner, experience_provider, admin
is_suspendedYes/No1Whether the account is suspended by admin
is_approvedYes/No1Whether the account has been approved
security_questionText255Used for password recovery
security_answerText255Answer to security question
created_atDateTime4Date and time account was created

Table: listings

Field NameData TypeSize (bytes)Remarks
idNumber4Unique ID for each listing (Primary Key)
user_idNumber4Foreign Key → links to Users table (owner of listing)
titleText255Listing title
descriptionText (Long)VariableFull description of the listing
locationText255Specific address/area
cityText100City name
priceCurrency5Base price of listing
statusText (fixed options)1Options: pending, approved, rejected
typeText (fixed options)1Options: tour_guide, shop, hotel, experience
created_atDateTime4Date and time listing was created
is_deletedYes/No1Soft-delete flag (1 = hidden, not permanently removed)

Table: listing_images

Field NameData TypeSize (bytes)Remarks
idNumber4Unique ID for each image (Primary Key)
listing_idNumber4Foreign Key → links to Listings table
image_pathText255File path to image, not the image itself

Table: hotel_listings

Field NameData TypeSize (bytes)Remarks
idNumber4Unique ID (Primary Key)
listing_idNumber4Foreign Key → links to Listings table
star_ratingNumber4Hotel rating from 1 to 5 stars
amenitiesText (Long)VariableComma-separated list of hotel amenities
total_roomsNumber4Total number of rooms in the hotel
check_in_timeDateTime (Time only)3Standard check-in time
check_out_timeDateTime (Time only)3Standard check-out time

Table: rooms

Field NameData TypeSize (bytes)Remarks
idNumber4Unique ID (Primary Key)
hotel_listing_idNumber4Foreign Key → links to Hotel Listings table
descriptionText (Long)VariableRoom description
room_typeText (fixed options)1Options: single, double, suite, family
price_per_nightCurrency5Price for one night
capacityNumber4Maximum number of guests
is_availableYes/No1Whether the room is currently available

Table: shop_listings

Field NameData TypeSize (bytes)Remarks
idNumber4Unique ID (Primary Key)
listing_idNumber4Foreign Key → links to Listings table
shop_typeText100e.g. Jewellery, Souvenir
open_timeDateTime (Time only)3Shop opening time
close_timeDateTime (Time only)3Shop closing time

Table: experience_listings

Field NameData TypeSize (bytes)Remarks
idNumber4Unique ID (Primary Key)
listing_idNumber4Foreign Key → links to Listings table
experience_typeText100e.g. Historical, Photography
durationText100e.g. "2 hours"
max_group_sizeNumber4Maximum people allowed per group
availabilityText255e.g. "Daily", "Weekends only"

Table: tourguide_listings

Field NameData TypeSize (bytes)Remarks
idNumber4Unique ID (Primary Key)
listing_idNumber4Foreign Key → links to Listings table
languagesText255Languages spoken by the guide
specializationText255e.g. Historical, Adventure
experience_yearsNumber4Years of guiding experience
availabilityText255e.g. "Daily", "Weekdays only"

Table: tourguide_licenses

Field NameData TypeSize (bytes)Remarks
idNumber4Unique ID (Primary Key)
user_idNumber4Foreign Key → links to Users table
license_numberText100Official tour guide license number
license_imageText255File path to uploaded license image

Table: bookings

Field NameData TypeSize (bytes)Remarks
idNumber4Unique ID (Primary Key)
tourist_idNumber4Foreign Key → links to Users table (tourist who booked)
listing_idNumber4Foreign Key → links to Listings table
statusText (fixed options)1Options: pending, confirmed, cancelled, completed
start_datetimeDateTime8Booking start date and time
end_datetimeDateTime8Booking end date and time
guest_countNumber4Number of guests included in booking
total_priceCurrency5Total price of the booking
commission_amountCurrency5Platform's commission earned from this booking
created_atDateTime4Date and time booking was made

Table: booking_rooms

Field NameData TypeSize (bytes)Remarks
booking_idNumber4Foreign Key → links to Bookings table (part of Composite Primary Key)
room_idNumber4Foreign Key → links to Rooms table (part of Composite Primary Key)

Table: payments

Field NameData TypeSize (bytes)Remarks
idNumber4Unique ID (Primary Key)
user_idNumber4Foreign Key → links to Users table
shop_listing_idNumber4Foreign Key → links to Shop Listings table (used for listing fee payments)
booking_idNumber4Foreign Key → links to Bookings table (used for booking payments)
typeText (fixed options)1Options: booking, listing_fee
amountCurrency5Payment amount
payment_statusText (fixed options)1Options: pending, completed, failed
fee_monthNumber4Month number, used only for listing fee payments
fee_yearNumber4Year, used only for listing fee payments
payment_dateDateTime4Date and time payment was made

Table: reviews

Field NameData TypeSize (bytes)Remarks
idNumber4Unique ID (Primary Key)
tourist_idNumber4Foreign Key → links to Users table
listing_idNumber4Foreign Key → links to Listings table
booking_idNumber4Foreign Key → links to Bookings table
ratingNumber4Rating score, restricted to 1–5
commentText (Long)VariableReviewer's written comment
created_atDateTime4Date and time review was posted

Table: messages

Field NameData TypeSize (bytes)Remarks
idNumber4Unique ID (Primary Key)
sender_idNumber4Foreign Key → links to Users table
receiver_idNumber4Foreign Key → links to Users table
listing_idNumber4Foreign Key → links to Listings table (message relates to this listing)
messageText (Long)VariableMessage content
is_readYes/No1Whether the message has been read
created_atDateTime4Date and time message was sent

Table: notifications

Field NameData TypeSize (bytes)Remarks
idNumber4Unique ID (Primary Key)
sender_idNumber4Foreign Key → links to Users table (usually admin/system)
receiver_idNumber4Foreign Key → links to Users table
messageText (Long)VariableNotification content
is_readYes/No1Whether the notification has been read
created_atDateTime4Date and time notification was created

Table: commission

Field NameData TypeSize (bytes)Remarks
idNumber4Unique ID (Primary Key)
rateCurrency3Commission rate value (percentage or fixed fee)
typeText (fixed options)1Options: booking_commission, listing_fee
updated_byNumber4Foreign Key → links to Users table (admin who made the change)
updated_atDateTime4Date and time rate was last updated
